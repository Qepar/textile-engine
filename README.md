# Textile Engine

A custom 3D cloth simulation engine in pure Python. It implements Position-Based Dynamics (PBD) for stable and realistic fabric deformation, with no dependencies on external physics engines.

## Features
- 100% original implementation
- Position-Based Dynamics for stability
- Custom constraints (distance, bend, shear, anisotropic)
- Collision detection (ground, spheres)
- Wet fabric simulation
- Real-time OpenGL rendering
